# ERA FC

世界杯 / 欧冠 / 欧洲杯 / 美洲杯跨年代足球选秀与逐轮杯赛。纯静态 ES modules，零 npm 运行依赖。当前界面 R20：独立大厅、Mini Games / Daily Card / 七人制、可控背景音乐与点击音效、三位房间码，以及单人 / 多人共享杯赛。

## 运行与部署

学校电脑只能使用网页时，参见 [GitHub Actions 发布说明](docs/github-deploy.md)：配置两个仓库 Secrets 即可从 GitHub 构建并发布到原 Cloudflare 网址，绕过 Cloudflare 构建环境初始化。

```sh
npm test
npm run dev
```

本地需要 Node.js（测试）和 Python 3（3000 端口 HTTP 服务）。不要通过 `file://` 打开 ES modules。
当前网站为 https://era-ball.ycxaaron.workers.dev ，由 Cloudflare Workers 托管，`main` 推送后触发构建。构建命令 `npm run build`，部署命令 `npx wrangler deploy --name era-ball --assets ./dist --compatibility-date 2026-10-19`；仓库 `wrangler.json` 也已配置日期。旧 Netlify 站点受额度限制，不能用它判断当前版本。

## 当前评分与稀有度

初始能力最多 110，羁绊后的实际能力没有上限。`fit()` 在位置、年代、羁绊结算后只保留下限 15；服务器使用相同公式，不把结果压回 100 或 110。

| 等级 | 实际能力 |
| --- | --- |
| S+ | ≥105（初始卡 105–110，羁绊可突破） |
| S | 98–104 |
| A | 90–97 |
| B | 82–89 |
| C | 75–81 |
| D | ≤74 |

用户最初给的 S 88–105 与 A 90–97 有重叠，本版按不重叠的推荐区间实现。后续可统一调整 `data.js` 的等级函数。

129 支精选球队年代：世界杯 45、欧冠 44、欧洲杯 20、美洲杯 20，共 2778 条球员版本、2025 个不同身份。本次新增 24 组球队年代、518 条版本，其中 397 个此前没有收录的身份。初始分布：S+ 36、S 145、A 734、B 1208、C 559、D 96；S/S+ 约 6.5%，A/B 约 69.9%。这是全库占比，不是单轮固定掉落概率：十一人玩法先等概率抽来源年代，再抽该年代球队。新增球员沿用评级平衡，不普遍提高评级。

`rating-balance.js` 以 A/B 为主，仅对明确挑选的历史巅峰版本设置 S/S+，同名球员不同年份独立评分。后卫保留卡纳瓦罗、马尔蒂尼、范戴克、卡洛斯、拉姆等少量 S+，前场顶级版本更多。旧 `defense-ratings.js` 只为旧缓存保留，不再参与当前评分。没有每队最多三名 S 的硬限制。

评分为游戏编辑估值，不是 FIFA 或官方统计。名单为精选阵容，不保证所有历史报名均完整。来源与边界见 [年代研究](docs/era-research.md)、[球员资料](docs/player-metadata.md)。

## 选秀与卡片

- 12 个可选征战年代、按赛事实际收录的来源年代、11 首发 + 5 替补、3 次额外重转。赛前锁定征战年代，可排除来源年代。
- 每轮按 Spin，球队和年代滚动停定后显示候选。确认选人后等待下一次 Spin，不自动抽下一组。
- 候选卡显示中文名字、身高、自然位置、初始能力与原始等级；头像为原创人物剪影。
- 先选人，再点击阵容空位试位，第二次点击同一空位才确认。试位不消耗选人，也不提交联机。
- 阵容卡使用实际能力决定等级与边框；数值不同于初始值时标出 `was S+` 等原始评级，位置行不重复写等级字母。
- 自然位置不扣分，邻近位置 −4、其他外场错位 −12、门将错位 −45。特定年代角色另扣 0–3，多数不扣；范戴克不额外扣年代分。
- 六种可选阵型：4-3-3、4-3-3 进攻型（前腰 + 两中前卫）、3-3-4、4-2-4、4-2-3-1、4-3-1-2。旧阵型仅用于读取历史存档，不出现在新选择列表。阵型可切换，球员保留原来的槽位，每个已确认球员固定在原位置，不能换位、替换或移出；试位仍可更换空位。

## 羁绊

12 组双人搭档首发或替补均可激活，每组各 +2，双人累计每人最多 +3。三人组只需三人都在本队 16 人名单内，替补与错位也可激活：BBC / MSN 各 +5，荷兰三剑客每人固定 +5。三人加分与双人加分取较高值，不重复相加；实际能力可继续突破 110，例如 110 梅西 +5 =115。

[羁绊说明与历史依据](docs/chemistry-research.md)区分真实同队经历和编辑加分规则。服务器从目录及实际 16 人名单重新计算，不信任客户端提交的能力值或羁绊身份列表。

## 界面与特效

`atelier.css` 使用深色胡桃木纹、石墨面板、暖金属按钮和米白文字，球场保留低饱和绿茵。原创木纹为 `assets/walnut.svg`；没有外站图片或字体依赖。参考站访问被代理拒绝，因此视觉按用户描述的木质与高级感方向重做，不宣称逐项复制。

105–109 的 S+ 使用白色边框与 12 个白色星尘，保留紫色分叉闪电，闪电震动但卡牌静止。当前能力达到 110（含）改为白色边框与黑白星尘旋涡，出现 14 个白色粒子、发光轨道，以及更明显的卡牌漂浮与摇晃。候选按初始能力、阵容与试位按实际能力触发，跌回 109 就移除暗物质效果，仍按实际评级保留对应边框。直接确认 110+ 入队，或羁绊让已有球员首次达到 110，会播放约 0.9 秒的柔和压暗背景、渐变卡位聚光、砸落与白雾觉醒，播放期间暂停下一次抽卡，不在试位和刷新时重播。确认 S+ 入队保留一次冲击环、白雾与压落，联机等服务器成功才播放。所有动态效果尊重系统减少动态效果设置。

## 赛季与难度

独立 `#season` 页面分阶段展示：四组各四队、小组赛三轮前二晋级、四分之一决赛、半决赛、决赛，均单场。是自定义 16 队杯赛，不冒充某年欧冠真实赛制。历史战报、积分与个人榜可查看，不把所有阶段挤到一屏。

自动模拟每 300 毫秒揭晓一场，到决赛前停止；决赛需手动开始。单人可 Skip to end。直播常规时间约 8 秒走完 90 分钟，平局再约 2.67 秒加时，仍平后逐脚点击点球。点球前五轮可提前结束，之后成对突然死亡，点球不计入射手榜。终场才展示冠军、双方 MVP 及赛季奖项。

单人和多人电脑对手均按真实阵容与位置选人，当前默认额外加 1 分（R14 单人下调 1 分、多人下调 2 分），欧洲杯/美洲杯电脑场上平均上限为 92。决赛进球系数保留单人 0.76、多人 0.88，其他轮次不变。1000 个固定种子的 94 分均衡队，单人冠军从 213 次降到 146 次；双人样本中房主冠军从 228 次降到 148 次。实力仍影响结果，也保留爆冷。这是校准样本，不是胜率承诺。全员刷新并新建房间使用新难度；混有旧浏览器标签页时，新端回退到旧版多人参数，避免两边模拟不一致。

两人联机在 A/C 组不同半区，只有都晋级才在决赛会师；三、四人各占独立小组，晋级后可能在淘汰赛交手。提前出局仍可继续观看。服务器保存共同种子、轮次、决赛时钟和已揭晓点球数；相同种子与目录在浏览器确定性重现赛果。尚非完整服务端权威比赛引擎，朋友间原型不防客户端篡改随机 Spin 或重转次数。替补暂不自动换人，离开者名额不自动释放。

## 联机安装或升级

在原 Supabase 项目执行一次 [setup-all.sql](supabase/setup-all.sql)，它已包含初始化、2778 条新版能力、全部羁绊、阵型、赛季及直播接口，可从空项目安装，也可重复升级已有项目。不要分别补跑旧脚本。v8 将基础目录约束从 100 扩到 110，移除实际能力上限，并以 `rating_version: 8`、`room_version: 13` 阻止旧库与新版网页混用。

确认 Authentication → Sign In / Providers 的 Allow new users to sign up、Allow anonymous sign-ins 已开启并保存。公开项目配置已填好，不填 service_role、secret key 或数据库密码。双方强制刷新原网站、新开一局，房主选择 2/3/4 人创建房间，朋友在独立设备或身份用 3 位房间码加入。必须全部设定人数选满 16 人才开赛。每约 1.5 秒 HTTP 轮询同步，无需另配 Realtime publication。

[完整逐步说明](docs/online-setup.md)。数据库脚本不删除原 `teams/players` 表或房间、阵容、赛果和点球进度；更新了能力与比赛引擎后仍建议新开一局，避免旧缓存混用。

## 验证

`npm test` 检查数据、评级边界、位置/年代/羁绊、无上限能力、稀有度、完整选秀与确定性赛季，以及难度样本。`npm run build:database` 根据当前目录生成 SQL。

可选集成测试：设置 `ERA_PGLITE_MODULE` 为 PGlite 模块路径，执行 `npm run test:database`，验证从空库完整安装、重复运行、原子版本锁、服务器能力重算及共同赛季/点球进度。再设置 `ERA_PLAYWRIGHT_MODULE`，可运行 `tests/browser-atelier.mjs`、`tests/browser-season.mjs`、`tests/browser-protocol.mjs`；浏览器可由 `ERA_CHROMIUM` 指定，默认 `/usr/bin/chromium`。需先启动本地 3000 端口服务。

浏览器联机测试把请求接到本地 PostgreSQL 测试库，不代表托管 Supabase 已更新；托管端仍需用户执行完整 SQL。

## 球队设置、重开与多人联机

首次访问显示队名设置卡，也可随时通过页头“球队设置”修改；1–20 字符，浏览器保留。队名显示于阵容、赛程、积分、冠军及其他玩家的房间面板。所有输出按文本转义，联机进入后本局名字锁定，服务器也校验冻结。重名在赛季中附加席位编号，避免两队难以区分。

页头、阵容页脚、赛季页顶部均有“重开”：确认后停止模拟/直播、离开当前房间、清空本局阵容和本地赛季进度，保留队名，直接进入赛前设置。无需切换赛事或刷新。

“检测连接”分别检查匿名登录和数据库能力，等待创建时不再把“尚未连接”当成失败提示。创建房间前未完成赛前设置的，保存设置后自动继续创建。数据库不匹配提供完整 SQL 复制按钮；匿名登录关闭时给出具体开启位置。

房间席位在服务器串行分配，人数上限 2–4，所有成员都完成阵容后才产生共同赛季。球员版本锁仍对整个房间生效。创建前检查保留名单是否足够所有人选满，避免欧洲杯/美洲杯单一旧年代只有一支球队而多人无球可选的死局。可用身份容量按每个身份的版本数与房间人数较小值求和，至少需 `16×人数`。

新增赛事名单见 [欧洲杯与美洲杯资料说明](docs/international-rosters.md)。欧洲杯现有 8 个来源年代，美洲杯 7 个，无球队年代明确标记不可作为来源抽取；征战战术年代仍可选全部 12 个。

可选测试：`tests/multiplayer-four.mjs` 验证三人美洲杯、四人欧洲杯及升级幂等；`tests/browser-four.mjs` 从首次命名、连接检测和真实创建/加入 UI 开始，用四个浏览器走完共同赛季、决赛、奖项、重开与美洲杯选秀。两者均使用本地 PostgreSQL 测试库，托管 Supabase 仍需手动运行完整 SQL。

## 静态发布与版本核对

Cloudflare Workers：构建命令为 `npm run build`，部署命令为 `npx wrangler deploy`。仓库根目录的 `wrangler.json` 已配置项目名、静态资源目录和必需的兼容日期。原部署命令 `npx wrangler deploy --name era-ball --assets ./dist` 也会读取该配置。若重试的是补配置之前的旧提交，可在 Cloudflare 构建设置中使用 `npx wrangler deploy --name era-ball --assets ./dist --compatibility-date 2026-10-19`，避免旧提交缺少配置。

`npm run build` 生成 `dist/`，Netlify 自动执行此命令并发布该目录。每次构建按内容哈希为完整 JS 模块图和 CSS 使用独立的 `releases/<hash>/` 路径，避免首页更新但依赖模块仍是旧版。首页与 `release.json` 禁止缓存，资源目录使用不可变缓存。页脚显示“星尘版 · R20 · <hash>”用于核对实际加载版本；GitHub 已推送不等于线上已发布，部署状态须在 Cloudflare 的 Deployments 确认。

## 大厅与短房间码

首页先选单人或联机，再选赛事。单人进入赛前年代设置；联机进入创建/加入房间，房主创建时再锁年代。返回大厅保留当前选秀，可点击继续；重开、开始新赛事和进入联机直接执行，不弹浏览器二次确认；新开局会清空本局阵容，球队名保留。选秀页不再显示四个赛事切换按钮。旧存档可从大厅继续，`#draft` 保留为直接进入选秀的路由；`#season` 恢复杯赛。

新房间码使用 A–Z、0–9 共三位（46656 种）。数据库用唯一键并原子重试冲突，最多重试 100 次，不能假设短码永不碰撞。旧 8 位十六进制码仍可加入。完整 SQL 升级保留已有房间，新建房间采用三位码。

## Mini Games / Daily Card / 七人制

在单人、联机入口下方进入 Mini Games。Daily Card 为 12 次机会的无限猜球员玩法，支持球员版本搜索、紫/金/灰反馈、方向箭头、Give up、答案揭晓、直接重开与本设备进度保存，不影响原选秀。完整规则见 [Daily Card](docs/daily-card.md)。

## 声音

右下角“声音”可开关原创电影感运动配乐、调整音量或关闭点击音效。R19 使用全新 108 BPM 合成弦乐、低鼓与长音主题，32 小节约 71 秒，分为铺陈、推进、间奏和高潮。跨大厅、选秀、比赛及小游戏连续播放；保留设备上的静音偏好。详情见 [声音与赛事曲目](docs/music.md)。音乐本身不需要 SQL；R20 新增球员用于十一人联机时需运行最新合并 SQL。

## 七人制 Mini Game

从 Mini Games → 七人制进入，1 名门将 + 6 名场上球员，四套阵型。只选年代、不选赛事；全部四类来源按球员国家归类，同一国家/年代/身份取最高初始能力版本，共 68 个国家、241 组国家年代、2401 张去重候选。手动 Spin、3 次额外重转、两次确认、永久槽位、动态评级和现有羁绊生效。独立本地存档、八队单场淘汰杯赛、三轮冠军；不覆盖十一人选秀。本版本七人制为单人玩法，不使用 Supabase，详见 [七人制说明](docs/seven-a-side.md)。
