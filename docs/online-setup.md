# 在原网站开启联机：完整步骤

继续使用原网站 https://era-ball.netlify.app 、原 GitHub 仓库和原 Supabase 项目。不用重新创建任何项目，不用 StackBlitz，不用再次下载或上传网站文件。

## 1. 复制这一份完整 SQL

打开 [setup-all.sql](https://github.com/ycxaaron-a11y/era-ball/blob/main/supabase/setup-all.sql)。点击代码区域右上方的复制按钮；也可点击 Raw，使用 Command+A / Ctrl+A 全选，再复制。

这是整份可执行代码，包含初始化、球员与年代目录、版本抢选锁、双人/三人羁绊（替补、错位同样激活）、新版稀有度与 110 基础能力、无上限实际能力、六种阵型、共享赛季和决赛直播、逐脚点球，以及本次 2260 条球员记录。之前的升级一个都没做过，也只需要这一份。已经升级过的项目也可以重跑。

## 2. 到原 Supabase 项目运行

1. 打开你原来的 **Eraball Soccer** 项目。
2. 左侧点击 **SQL Editor**（SQL 图标）。
3. 点击 **New query / +** 新建查询。
4. 粘贴刚复制的全部代码。
5. 点击右上角绿色 **Run**。
6. 看到 **Success. No rows returned** 即成功。若报错，保留报错文字以便排查，不需要删除表或重建项目。

脚本按一个事务执行，不清空旧的 `teams`、`players`、房间、阵容或赛果。不要分别再执行之前那些初始化/升级脚本。

## 3. 确认匿名登录已开启

1. 左侧进入 **Authentication**。
2. 点击 **Sign In / Providers**（有的界面叫 Providers）。
3. 将 **Allow new users to sign up** 和 **Allow anonymous sign-ins** 设为开启。
4. 点击 **Save changes**。如果已经开启并保存，保持即可。

不需要关闭 Confirm email，也不需要配置邮箱或注册账号。网站会为每位玩家建立匿名身份。

## 4. 刷新原网站

等 Netlify 最新部署显示 **Published**，打开 https://era-ball.netlify.app 。Mac 按 **Command + Shift + R**；Windows 按 **Ctrl + Shift + R** 强制刷新，朋友也要刷新。页脚应显示“星尘版 · R13”及版本编号；如果仍没有这个标记，请先到 Netlify → Deploys 确认最新提交已 Published，避免在旧页面反复升级数据库。建议本次从新一局开始，避免新旧球员目录和比赛引擎混用。

项目地址和 publishable key 已经放在网站公开配置中，不需要重新填写。不要把数据库密码、secret key 或 service_role key 填到网页。

## 5. 设置队名、创建 2–4 人房间

1. 首次进入时填写球队名；之后可点页头 **球队设置** 修改。名字会让其他玩家看到。
2. 房主选择 **世界杯 / 欧冠 / 欧洲杯 / 美洲杯**，点击 **联机对战**，先点 **检测连接**。
3. 检查通过后选择 **2 人、3 人或 4 人**，点击 **创建房间**。若尚未设置征战年代，会先打开赛前设置；保存后自动继续创建。
4. 将同一个网站网址及 **8 位房间码** 发给朋友。朋友点 **联机对战 → 输入房间码 → 加入房间**，自动采用房主模式及年代。
5. 按设置人数全部加入、各自选满 16 人后进入同一届杯赛。确认球员入队后固定在该位置，杯赛开始前阵型仍可切换（包括自己选满但仍在等待朋友时），球员保留原槽位并重新计算位置适配。不要创建四人房间却只来两个人，否则会等待其余玩家。
6. 两人分属不同半区；三、四人分别进入独立小组，晋级后可能在淘汰赛交手。任意成员推进轮次，所有成员同步。
7. 自动模拟在决赛前停止，手动开始决赛；常规时间约 8 秒，必要时加时和逐脚点球。多个人同时点点球仍只共同揭晓一脚。
8. 想再玩一局，点页头或赛季顶部 **重开**。队名保留，阵容清空；联机需重新创建房间并发送新码。

欧洲杯和美洲杯有些早期来源年代暂未收录，会标记不可选。多人房间还会检查保留的名单是否足够；若提示名单不足，请取消一些 Lock。
测试请使用两台设备，或两个独立浏览器/无痕身份；不要用共享同一身份的页面冒充两名玩家。界面通过约 1.5 秒轮询同步，无需另外开启 Realtime publication。

## 网站提示需要升级时

联机提示里也有 **复制升级 SQL** 按钮，它复制的就是同一份 `setup-all.sql`。复制后从第 2 步继续。如果连接仍失败，把提示的具体文字保留下来排查，避免重复创建项目。
