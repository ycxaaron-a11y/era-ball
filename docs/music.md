# 原创背景音乐

R21 换成 MATCHDAY · 比赛日：116 BPM、32 小节约 66 秒的原创电钢琴律动。移除 R19/R20 的弦乐和电影式铺底，重新编写旋律、七和弦、切分贝斯和轻鼓组。电钢琴由衰减的多组正弦泛音合成，不是实录乐器或已发行歌曲。主段、间奏和最后变奏在同一循环里自然推进，不使用尖亮铜管或高音提示旋律。

首次用户交互后启动，右下角可调音乐音量、关闭音乐或独立关闭按钮轻点音效。已有音量和静音偏好保留。界面切换，包括七人制联机与决赛，不换曲、不重头开始。隐藏页面或关闭音乐时停止调度，回来或再开启后继续步进；刷新整页重新开始。

完全本地合成，不上传、下载或请求外部播放器。独立确定性噪声不调用游戏随机数。关闭时清理节点；压缩器控制峰值。浏览器测试检查播放、循环、音量、关闭、切页不重启和完整离线渲染的平均音量、峰值。音乐喜好仍以实际试听为准。
