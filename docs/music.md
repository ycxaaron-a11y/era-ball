# 声音与赛事曲目

右下角“声音”提供背景音乐、音量、按钮音效与播放方式。点击音效默认开启，背景音乐需在面板中开启；设置保存在本设备。歌曲通过 YouTube 播放器播放，也可以选择本设备的音频文件。已经取消合成背景音乐和任何自动替代，按钮短音效保留。

大厅预设用户提供的 [Let Go](https://www.youtube.com/watch?v=4VvAUcJ2Yms)，Beau Young Prince，《Spider-Man: Into the Spider-Verse》。播放器只循环该视频，不使用推荐电台列表。世界杯 2010–2014 区间已配置 [Waka Waka](https://www.youtube.com/watch?v=pRpeEdMmmQ0)。不复制、下载或托管这些录音。

R16 去掉了 URL 中的强制静音，使用明确的“播放 / 解除静音”、重试和直接打开 YouTube 的入口。自动播放拦截、接口连接失败及视频错误会显示具体原因。错误 101/150 表示发布者禁止站外播放，100 表示视频不可用，153 表示来源验证问题。站点不能绕过网络不可达或平台禁止嵌入；测试中的视频播放器为可控模拟，不代表已验证用户所在网络的实际视频播放。

本地音频支持浏览器能解码的 MP3、M4A、WAV 等格式，选择文件后在本设备循环播放，不上传服务器。刷新后因浏览器权限限制需要重新选择文件。音乐可以独立暂停、调音量；音效开关互不影响。没有配置视频时保持安静，并提示添加链接或选择本地音频。

曲目选择按征战年代区间内的第一届赛事。例如 2010–2014 区间对应世界杯 2010；欧洲杯 2015–2019 区间对应 2016。欧冠使用 1992 年启用的经典主题，不将其称作 1960 年代的官方主题。其他年代歌名是待核对和配置的参考，不能视为全部已经在线核验或接入；美洲杯也没有伪造具体歌曲。面板保存的播放链接只影响本设备，若要全站默认使用某个视频，需在曲目目录中配置确认过的链接。

音效使用本地合成短音，不调用游戏随机数，不影响抽卡或模拟赛果。页面隐藏时暂停音乐。首次播放仍可能需要用户手动点击；所有外部播放均受实际网络、浏览器和平台限制。
