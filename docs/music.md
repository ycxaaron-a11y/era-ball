# 原创背景音乐

R17 使用浏览器本地合成的原创电子运动配乐，已移除外部歌曲、YouTube 播放器、歌曲链接以及音频导入入口。不需要下载音乐，也不依赖外部播放器。

三段配乐共用原创主题，并根据场景调整速度、节奏与编曲：

- 大厅 / 小游戏：KICKOFF · 开场哨，128 BPM。
- 选秀：FLOODLIGHTS · 聚光时刻，132 BPM，增加琶音层次。
- 模拟赛季：EXTRA TIME · 决胜时刻，136 BPM，增加密集踩镲与冲刺节奏。

每段包含四拍底鼓、军鼓、开闭镲、双层合成贝斯、和弦、主旋律与延迟回声。16 小节循环包含鼓花、短暂间奏与高八度变奏。音乐经过压缩器控制动态；使用独立音量，按钮短音效也可独立开关。此曲没有使用或仿作某首既有歌曲的录音、旋律。

首次点击页面后启动音频，默认音乐音量为 45%；已经保存的音乐关闭偏好和音量会保留。右下角“声音”可以重新开启。浏览器不支持 Web Audio 时会提示。页面隐藏时停止播放并清理节点，回来后恢复；关闭背景音乐会停止调度并清理节点，避免多个循环叠加。内部使用独立确定性噪声，不调用游戏随机数、不影响抽卡与赛果。

实现见 `music-engine.js`；浏览器测试使用真实 AudioContext 验证启动、关闭、场景切换和本地离线渲染的有效音量与峰值，不依赖模拟外部播放器。
