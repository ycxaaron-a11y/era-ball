# 声音与赛事曲目

右下角“声音”提供背景音乐、音量、按钮音效与播放方式。点击音效默认开启，背景音乐首次需在面板中开启；设置保存在该设备。后续已开启的音乐在首次用户交互后尝试启动，遵守浏览器自动播放限制。切换场景改变曲目，同一选秀中重复渲染、选人和 Spin 不重启同一首音乐。

大厅预设为用户提供的 [Let Go](https://www.youtube.com/watch?v=4VvAUcJ2Yms)，Beau Young Prince，《Spider-Man: Into the Spider-Verse》。播放器只循环该视频，不使用链接附带的推荐电台列表。世界杯 2010–2014 年代区间已配置 [Waka Waka](https://www.youtube.com/watch?v=pRpeEdMmmQ0)。这里没有复制、下载或托管这些录音；用可见的 YouTube 播放器播放，支持在面板中指定每首曲目的视频链接。未自动启动时，可点击播放器内的播放键。停止背景音乐会销毁播放器。

曲目选择按征战年代区间内的第一届赛事。例如 2010–2014 区间对应世界杯 2010；欧洲杯 2015–2019 区间对应 2016。欧冠使用 1992 年启用的经典主题，不将其称作 1960 年代的官方主题。没有核实、配置的曲目明确提示，并回退到本站用 Web Audio 合成的原创氛围音乐；切勿将该合成音乐当作实际赛事歌曲。

本次外部音乐目录查询未完成，`music-catalog.js` 中其他年代的歌名是后续核对和配置的参考，不能视为全部已经在线核验并接入。美洲杯也没有伪造具体歌曲。面板提供查找入口和本设备的视频链接设置；若要全站使用某首视频，需要在目录中配置经确认的链接。用户提供的 Let Go 视频已预设给全站玩家。

原创氛围音乐和短点击音效均为本地合成，无需联网。按键音效不使用游戏的随机数生成器，不影响抽卡及赛季结果。页面隐藏时暂停音乐；关闭音效不影响音乐，反之亦然。音量和静音分别控制，可随时关闭。
