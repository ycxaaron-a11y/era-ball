# 原创背景音乐

R18 使用统一的原创曲目 ONE PITCH · 同一片球场，120 BPM，16 小节循环。编曲为手鼓、底鼓、轻拍背拍、拨弦和温暖的贝斯，保留运动节奏；去掉 R17 中锯齿波音色、高八度旋律和密集琶音，减少突兀的电子鸣叫。按钮音效改为无固定音高的短促轻点声。

音乐从首次用户交互后开始，跨大厅、选秀、赛季和小游戏保持同一个循环与进度，不再按界面切换曲目、速度或重启。开关和音量仍独立控制。隐藏标签页时停止调度，回来后从下一步继续；手动关闭再开启也保留步进位置，刷新页面则重头开始。

默认音乐音量为 45%；已保存的静音与音量偏好保留。右下角“声音”可重新开启。完全在浏览器内合成，无音频上传、下载或第三方播放器请求，内部独立噪声不影响抽卡和比赛随机数。音乐经过压缩控制峰值，关闭时清理节点，不会叠加多个循环。

本次尝试访问世界杯歌曲 Waka Waka 的 YouTube 官方视频信息接口，但开发环境代理返回 403，无法验证该录音可可靠嵌入。没有把未验证的录音、下载链接或音乐预览冒充成可用背景音乐，因此采用用户同意的原创备选方案。此曲不是世界杯官方主题曲，也没有使用其旋律或录音。

实现见 `music-engine.js`；测试使用真实 AudioContext 检查循环、音量、静音、切页不重启和完整离线渲染，检查平均音量及峰值。
