# Daily Card

从大厅的 Mini Games 进入 Daily Card。采用当前足球名单中的 2260 个球员、球队、年份版本，支持无限轮练习；名称是玩法名称，并非一天只能玩一题。每轮最多 12 次有效猜测。

开局只公开目标的年代区间及原始等级。搜索支持中文、英文、常用别称、球队和年份。相同球员的历史版本分别展示，选择一个版本才计作猜测。正确答案要求球员身份、球队和具体年份一致。

| 对照项 | 紫色 | 金色 |
| --- | --- | --- |
| 球员 | 相同身份 | 不设置近似姓名 |
| 球队 | 同一球队 | 同国球队；或猜测球员在当前名单中曾效力过目标球队 |
| 洲别 | 同一洲 | 不设置近似洲别 |
| 地区 | 同一地理分组 | 同洲的其他地区 |
| 位置 | 位置集合相同，不计顺序 | 至少一个位置重合 |
| 身高 | 相同厘米数 | 相差不超过 5 cm |
| 年代 / 年份 | 具体年份相同 | 同一或相邻游戏年代区间 |
| 等级 | 等级相同 | 相邻一级 |

其余显示灰色。身高、年份和等级的 ▲/▼ 指向目标的方向。地理信息指该版本球队所在地，不是球员出生地；地区是本游戏维护的分组，不是篮球赛区，也不是官方足球分区。历史球队名称保留原名，例如西德、1991 年红星所在的南斯拉夫。

重复版本、未知输入和空输入均不扣次数。第 12 次仍猜错直接判负并显示完整答案；第 12 次猜中仍获胜。Give up 在零次猜测时也可以使用，立即揭晓答案，再来一轮不会抽中刚刚那张卡。刷新保留当前轮次及猜测，返回大厅不改变原选秀阵容。所有操作不使用浏览器确认弹窗。

这是本地小游戏，进度保存在该设备浏览器；不涉及 Supabase 升级。身高、等级和历史阵容沿用现有游戏资料与估值，不新增荣誉标签。未来小游戏可继续在目录中增加入口。
