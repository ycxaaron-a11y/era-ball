# R20 球队与球员扩充

新增 24 组真实球队年代，518 条球员版本，397 个新身份。全库从 105 组/2260 版本/1628 身份增至 129 组/2778 版本/2025 身份。每组精选 20–24 名球员，包含门将、后卫、中场、前场和替补深度；不保证等于完整报名表。

- 世界杯：乌拉圭 2010、日本 2022、韩国 2002、土耳其 2002、比利时 2018、葡萄牙 2022、喀麦隆 1990、瑞典 1994。
- 欧冠：阿森纳 2006、马竞 2014、多特蒙德 1997、瓦伦西亚 2001、里昂 2010、那不勒斯 2023、热刺 2019、PSV 埃因霍温 2005。
- 欧洲杯：捷克 2004、土耳其 2008、克罗地亚 2008、比利时 2016。
- 美洲杯：哥伦比亚 2001、巴拉圭 2011、墨西哥 2001、厄瓜多尔 2016。

评级属于游戏编辑估值，使用既有 `balanceRatings`，没有因名单变多就提高旧球员能力。新增稀有巅峰包括阿森纳 2006 亨利 105；全库 S/S+ 比例约 6.5%，A/B 约 69.9%。多位置、中文名、身高和身份复用原有资料流程。只有明确整理的常见身高作为资料录入，其他仍使用用户认可的稳定位置估值，内部保留估计标记。

## 本轮实际核对

实际读取了 [jfjelstul/worldcup 的 squads.csv](https://github.com/jfjelstul/worldcup/blob/master/data-csv/squads.csv) 和 [players.csv](https://github.com/jfjelstul/worldcup/blob/master/data-csv/players.csv)，对照以上八支新增世界杯队的成员姓名。核对时纠正了韩国崔成勇、瑞典米卡埃尔·尼尔松、喀麦隆博纳文图尔·琼凯普等成员，以及伊东纯也英文名。仅整理精选的球员事实，没有把其记录的前锋/中场粗分类当作精确自然位置，更不使用该数据生成游戏评分。

俱乐部、欧洲杯、美洲杯的精选成员及国别由人工整理，未声称每条记录都完成本轮联网官方验证。位置适应和能力估值不属于上述数据库提供的事实。历史双国籍、常用名、同名异人仍可能需要后续校正，不进行无条件模糊合并。

`catalog-variety.js` 为新增目录，十一人选秀及 Daily Card 自动使用。七人制汇合全部四类赛事版本，国别补充见 `player-countries.js`。联机服务端目录由 `npm run build:database` 生成，更新 [setup-all.sql](../supabase/setup-all.sql) 以及合并升级文件；现有 Supabase 项目运行最新完整文件即可，不重建项目、不删除旧房间或阵容。

联机状态包含目录版本。若房间中仍有扩充前的旧标签页，杯赛 NPC 选择回退到旧目录，保持共享种子下的同一赛程；全部玩家刷新并提交后使用新目录。建议大家刷新 R20 后开新房间。
