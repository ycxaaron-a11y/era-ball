# 中文显示与身高资料

中文位置、球员译名是界面显示字段，原有球员 identity、阵容槽位与存档编号保持不变。
本版覆盖全部 913 个球员身份的中文名。常用译名优先；较冷门球员采用中文音译，译名可继续校正。

## 身高

以厘米显示已收录的成年身高。身高不会额外影响评分、位置适配或模拟赛果，未将其伪装成已实现的头球模型。
当前 913 个身份中 453 个有身高记录；其余显示“身高待补充”，不会用随机数或按位置猜测身高。
不同年代、官方报名表、游戏资料及个人资料的测量/取整可能有差异，当前值不代表精确到一厘米的统一实测。

参考来源：

- [jokecamp/FootballData](https://github.com/jokecamp/FootballData)，MIT 授权，已附 [许可证](football-data-LICENSE.txt)。实际读取了 `World Cups/world-cup-2010/squads.csv`（含 Height）及 `video-game-data/fifa-soccer-12-ultimate-team-data-player-database.csv`。仅摘录名字明确匹配且没有数值冲突的现代全名条目，不导入整套游戏数据库，不使用其游戏评分。
- 其余为人工整理的常见资料身高，标记于独立 `player-heights.js`，可后续对照俱乐部及赛事球员资料校正。此轮直接访问 Wikipedia 的核对请求被环境代理拦截，不能宣称所有记录均做过在线官方复核。
- 旧球员、同名球员和冲突记录不做模糊自动匹配；例如不会把现代法尔考、佩佩、埃迪尼奥的身高自动套给早期同名球员。

## 交互

点击候选球员只选中候选，不保存选秀、不抽下一组、不发送联机提交。
第一次点击空位置，仅展示半透明试位和该位置的最终能力；第二次点击同一位置才提交球员。
改点其他空位会移动试位并重新等待确认；取消、更换候选、重转、切换阵型或刷新都会取消未确认试位。
候选卡显示中文姓名、身高、中文自然位置与评级，不显示基础/适配能力数值。完整能力计算仍可在入队后的详情里查看。
