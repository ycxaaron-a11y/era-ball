# 七人制 · 全时代混战（R21）

入口：大厅 → Mini Games → 七人制。提供单人混战及 2–4 人好友联机。它使用单独的七人存档/房间，不覆盖十一人选秀和赛季。

## 国家池：只有国家，没有年代锁定

按照用户修正，合并当前已收录的全部世界杯名单：45 组球队年代、1007 张具体届次版本、21 个国家。西德统一归德国。不再选择年代，不排除年代，不计算跨年代适配惩罚，也不将俱乐部/欧洲杯/美洲杯版本混入本玩法。

抽到巴西，就能从目前收录的 1962、1970、1982、1994、2002、2014、2018、2022 等届次一起选人。同一人不同届次均保留，卡面标注年份；同一支队伍内不能重复同一个身份。名单是现有精选库的跨年代合并，不声称覆盖历史上每届所有报名国家或所有球员。

每队 7 人，含 1 名门将和 6 名场上球员，没有额外替补。阵型为 2-3-1、3-2-1、2-2-2、3-1-2，均不计门将。选人继续使用手动 Spin、3 次额外重转、两次点击试位确认、永久槽位。球员可按姓名、位置或年份筛选。无年代惩罚，位置适配与既有羁绊仍生效；卡框按最终能力变化。

## 传奇对手

对每个国家，从全部世界杯届次中按身份挑选一套最合适阵容，并比较四种阵型的实际能力。前十强国家队打乱后用于组成八队七人杯，AI 有明确显示的 +2 传奇强度。对手强于原单年代版本，但仍采用有随机性的比赛模型，不保证人类或 AI 获胜。

## 七人制联机

与十一人共用匿名登录，使用独立 `fc7_*` 表和 RPC。需在原 Supabase 项目运行最新完整 `setup-all.sql`，一次合并全部旧升级与这次七人联机，不重建项目。

1. Mini Games → 七人制，填写队名，选择创建人数 2、3 或 4。
2. 创建房间，将同一网站和 3 位房间码发给朋友。朋友在七人制页面加入，不能在十一人联机页面混用房间码。
3. 各自选满 7 人，点击准备；满员且所有人准备后才生成一次共同赛程种子并开赛。
4. 两位玩家位于八队签表上下半区；三、四位分别占据不同四分之一区。晋级才能相遇，不保证玩家一定能进决赛。

服务端控制国家 Spin、重转次数、合法世界杯版本、门将槽、固定槽位、同人去重、同版本抢选锁、准备状态和修订号。朋友选走同届同人版本后，其他玩家仍能选该人的其他世界杯届次。同一请求重复提交不重复选人；争抢同版本只有一个赢家。抽中的国家如所有适合空位的候选都被锁定，可免费 Spin 更换，服务器验证已耗尽才能免费。

每 1.5 秒读取房间进度。刷新保留房间、名单、共同种子、轮次和决赛时钟。离开本界面或关闭页面不自动退出；回到七人页面可恢复。明确点击离开/重开时：房主离开会关闭房间；任何玩家在开赛后离开也关闭该房间，避免改变已固定的参赛名单。选人期间普通成员离开会释放其席位和版本锁。

## 决赛：8 秒常规时间，必要时加时和手动点球

四分之一决赛、半决赛逐轮模拟。到决赛必须点“开始决赛 · 90 分钟直播”，不能直接揭晓最终结果。0–90 分钟约 8 秒，事件随分钟逐个显示得分球员和比分；90 分钟平局继续加时，约 2.7 秒走完 91–120。仍平则每次点击只揭晓一脚点球，决出胜者后才显示冠军。

联机时使用服务器创建的不可重置开始时间、共同踢罚计数和时间偏移。多个人同时点击同一脚点球只共同推进一脚；刷新不重开直播。赛果由相同的规范球员 ID、共同种子和同版前端算法确定；不是把每一秒写到数据库，也不是服务端完整重放物理足球或实现专业反作弊。

单人存档为 `era-fc-seven-v2`。R20 的单年代存档为 v1，保留在原键下，不自动混入新规则。十一人存档不变。离开、重开不弹确认框，背景音乐跨界面连续播放。
